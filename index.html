THE PIPELINE

Four stages, four honest metrics.

Each stage is a self-contained chapter — and each has a number you can actually measure.

input · a photo, at an angle
01

The Photograph

It starts with a real, messy image — a board shot from across the table, tilted, uneven light. No assumptions about alignment.

classical CV · contours, Hough lines, homography

detect corners → warp to a clean 8×8
02

Finding the Board

Detect the four corners, then warp the perspective so the board becomes a flat, square grid — the hard, interesting part, where real photos fight back.

metric · board-detection success rate

a CNN classifies each of the 64 tiles
03

Reading 64 Squares

Slice the warped board into sixty-four tiles and run a CNN over each one — empty, or one of twelve piece classes. One square at a time, with a confidence.

metric · per-square & whole-board accuracy

… assemble predictions → a legal FEN
04

The Position → The Plan

Turn sixty-four predictions into a single legal FEN string — the universal language of a chess position — and hand it to a real engine for the best move.

downstream · Stockfish, the move, the eval
